# Шаблоны документов

Шапку заполняй по `frontmatter.md`. Ниже только тело. Новый файл получает `status: draft`, `quality: unrated`.

## vision
```
# Видение
> TL;DR: …
## Зачем проект
## Для кого
## Что считается успехом
## Что делает его особенным
```

```
# Границы

## Анти-цели (что провал, даже если технически работает)
```

## changelog
Формат Keep a Changelog: разделы `Added`, `Changed`, `Fixed`, `Removed`, `Security` под версиями или `Unreleased`.

```

## Правила документации → [[rules]]
```

## index (docs/_index.md)
```
# Индекс документации
> TL;DR: карта документов. Начни отсюда, открывай файл целиком только по необходимости.
## <Раздел>
| id | Название | type | status | quality | Суть |
```
Строки собираются из шапок. Порядок по разделам папок.

## rules (docs/_rules.md)
Содержит: ссылку на плагин и версию стандарта, раскладку папок проекта (если отличается от стандартной), словарь тегов, сроки устаревания, порядок работы для нейросети (см. `agent-pointer.md`, блок «Правила для нейросети»), список обязательных документов проекта и их пути.
